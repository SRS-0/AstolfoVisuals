# Astolfo Reborn


AstolfoClient is a lightweight PvP and visual client for Minecraft 1.21.4. It focuses on making the game look cleaner, giving you more control over your HUD, and adding visual effects without changing the way vanilla Minecraft feels.

The client comes with a custom ClickGUI, HUD editor, themes, visual effects, ESP options, custom animations, and several small quality-of-life features.
There are multiple particle types available, including stars, bubbles, hearts, snowflakes, and dollar symbols.

## Performance
Astolfo Reborn is designed to keep its visual features separate from the normal Minecraft gameplay as much as possible. Most effects can be enabled or disabled individually, so you can keep only the features you actually want to use.

If you prefer a clean setup, you can simply leave the visual effects disabled and use the HUD, animations, themes, and other customization features.

## Why Astolfo Reborn?
Astolfo Reborn is mainly about customization.

Instead of adding a huge number of complicated features that you may never use, the client gives you a collection of visual tools, HUD options, animations, effects, and small utilities that can be mixed together to create your own setup.

Whether you want a simple clean HUD or a more colorful PvP style interface, the client lets you configure it the way you want.

## Installation
1. Install Fabric Loader for Minecraft.
2. Install Fabric API.
3. Put `AstolfoClient` into your Minecraft `mods` folder.
4. Start Minecraft using your Fabric profile.
5. Open the AstolfoClient ClickGUI on `INSERT` and configure your settings.



`Astolfo Reborn is a client-side mod and does not need to be installed on the server!!!`
